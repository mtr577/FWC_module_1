For the output F to be 1 in the logic circuit shown, the input combination should be
\begin{center}
	\includegraphics[width=12cm, height=8cm]{images/circuit.jpg}
\end{center}
\begin{multicols}{2}
                \begin{enumerate}[label=\Alph*]
			\item A=1, B=1, C=0
                        \item A=1, B=0, C=0
			\item A=0, B=1, C=0
			\item A=0, B=0, C=1
		\end{enumerate}
\end{multicols}
\section*{\textbf{Question Analysis:}}
\begin{itemize}
	\item For Two input XOR Gate: Let output be $X= A\oplus B$
	\item For Two input XNOR Gate: Let output be $Y= A\odot B$
	\item For Three input XNOR Gate: output $F=X\odot Y\odot C$
	\item The Final $F$ expression is $F=(A\oplus B)\odot (A\odot B)\odot C$
	\item The Truth table for above expressions is as follows
\end{itemize}

\section*{Code Uploading Steps}
\begin{enumerate}
	\item Create a Platform IO project
	\item Write The code in main.cpp in src
	\item Run the PIO project with command "pio run". It will compile the code and creates .hex file
	\item Copy the .hex file to ArduinoDriod folder
	\item connect the Arduino UNO to mobile with OTG cable
	\item Upload the hex file using "upload precomplied" option
	\item Observe the ouput and verify the expression
